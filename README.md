# 15-Puzzle Game with Permutation Visualization

The 15-Puzzle is a well-known sliding puzzle board game. In its simplest version, 
15 numbered tiles are randomly arranged on a 4x4 grid containing 16 cells. 
One cell remains empty, allowing adjacent tiles to be slid into it. 
While the traditional rules only permit moving tiles into the empty space, this 
game includes the visualization of permutations (transpositions), permutation cycles, 
and inversions, so a free-swap mode is also available.

This program was developed as an educational tool for mastering permutations in 
algebra and group theory. I believe it will be primarily useful for students 
learning this kind of material.

Link to [the game and the transpositions matrix](https://anton-zaharov.github.io/fifty/index.html).

# Игра Пятнашки с визуализацией перестановок

Пятнашки - известная настольная игра-пазл. В самом простом варианте на поле 4х4 
из 16 ячеек в случайном порядке расставляются 15 пронумерованных костяшек. 
Одна ячейка остается свободной и на нее можно сдвигать соседние костяшки. 
По правилам действовать можно только сдвигами костяшек, но поскольку данная игра
сопровождается визуализацией перестановок (транспозиций), циклов перестановок, 
и инверсий, то есть режим для свободных замен. 

Данная программа разрабатывалась как учебное пособие по освоению перестановок в 
алгебре и теории групп. Считаю, что она будет полезна в первую очередь школьникам 
при освоении подобного материала.

Ссылка на [игру и матрицу перестановок](https://anton-zaharov.github.io/fifty/index.html).
