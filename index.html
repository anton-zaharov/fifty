Матрица перестановки

Строки — значение костяшки, столбцы — позиция на поле (E — пустое поле). Ход — это обмен столбца E с другим: по горизонтали - с соседним столбцом, по вертикали - с 4-ым справа/слева. Подсвечены допустимые для хода столбцы. Для совершения хода можно кликнуть по подсвеченному столбцу.
